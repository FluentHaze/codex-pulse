# Codex Pulse 使用指南

[返回首页](../README.md) · [下载最新版](https://github.com/FluentHaze/codex-pulse/releases/latest) · [反馈问题](https://github.com/FluentHaze/codex-pulse/issues)

本指南介绍已安装软件的配置和日常使用。先从[官网](https://fluenthaze.github.io/codex-pulse/)下载对应系统的安装包；首次安装步骤见 [README](../README.md#下载与安装)。

## 首次连接

1. 确认已安装 Codex，并已使用 ChatGPT 账号登录。
2. 打开 Codex Pulse，等待连接并读取额度。
3. 无法自动找到 Codex 时，在「偏好设置」中手动选择 Codex 可执行文件，随后刷新。
4. 在详情窗口核对账号信息和额度，按需设置语言、主题、登录启动及通知。

Mac 默认使用菜单栏显示额度，移入可查看额度卡片；Windows 使用桌面悬浮窗。Mac 用户也可在「偏好设置 → 悬浮窗」开启「显示桌面悬浮窗」。

## 查看额度

在「额度概览」查看已返回的额度窗口、剩余或已用比例以及重置时间。悬浮窗显示相同的额度状态，点击可进入详情。缺失数据会显示不可用，不代表无限额度。

关闭详情窗口后软件继续在后台监控；需要结束运行时，从菜单选择退出。通知和提醒需要软件保持后台运行。

## 查看用量图表

两个页面均默认选中「小时」，沿用本机时区：

| 页面 | 可选周期 | 显示范围与操作 |
| --- | --- | --- |
| 额度概览 | 分钟、小时、日 | 分钟限今天，可拖动、缩放；小时固定当天；日固定最近 15 天 |
| 今日用量 | 分钟、小时 | 分钟限今天，可拖动、缩放；小时固定当天 |

- **分钟**：蓝色和淡紫色并列柱分别表示今天、昨天同一分钟的用量。没有用量的分钟留空。拖动图表或底部选区查看当天其他时段，滚轮或加减按钮调整可见范围，拖动两端白色手柄调整选区。达到最小柱宽后停止缩小，可继续横向拖动。点击「回到最新」恢复最新时段。
- **小时**：按小时展示今天、昨天的圆滑面积曲线，不提供拖动和缩放。今天尚未到来的时段留空。
- **日**：显示含今天在内的最近 15 个自然日合计，今天为截至当前的已记录用量，不提供拖动和缩放。
- 悬浮可查看具体时段和数值；聚焦图表后可用方向键、Home/End 查看明细，Esc 关闭提示。

「今日用量」还展示合计、输入、输出、缓存和推理构成。页面打开时每 30 秒刷新，也可以手动刷新。分钟与小时只汇总今日、昨日所需的事件；切到日视图才读取最近 15 天。

## 查看聊天和逐轮用量

打开「Token 明细」，搜索或筛选项目、聊天和更新时间，再选择聊天查看每轮输入、输出及合计。点击轮次可查看消息和详细统计；仍可访问的本地图片可点击预览。

本机多个聊天并行时，可以「固定跟踪此聊天」，也可恢复自动跟随。悬浮窗展示的是用量事件写入本地记录后的近实时数据，模型运行期间数值可能暂时不变。

缓存输入属于输入的一部分，推理属于输出的一部分，不应再次加到合计。消息或计数缺失时会明确提示，不会根据消息文字估算 Token。

## 重置雷达与提醒

在「重置雷达」查看历史日历、公告和历史节奏。预测属于实验性参考，不是官方重置承诺，也不替代个人账号的重置时间。

低额度通知、全局重置通知及个人窗口提醒可按需开启。全局重置和个人窗口提前 15 分钟提醒默认关闭；日历导出位于相关操作菜单。第三方服务暂时不可用时，保留的旧数据会标记状态。

## 更新软件

在「偏好设置 → 版本更新」查看新版和下载进度。

发现新版、正在下载或更新就绪时，账号区上方会常驻显示提示与目标版本；窄窗口显示在内容区顶部。点击「查看更新」进入更新设置，下载完成后可直接点击「重启并安装」。安装前不会自动退出应用。

- Windows 安装版下载完成后点击「重启并安装」。
- Windows 便携版从发布页面下载新版，退出旧版后替换使用。
- Mac（v0.1.35 起）下载完成后点击「重启并安装」，应用会自动校验、替换并重新打开；需要管理员权限时按系统提示授权。v0.1.34 及更早版本需先手动退出、替换并打开新版一次。

更新保留已有设置；暂不安装可继续使用旧版。若更新失败，可在设置中重试，或从[官方下载入口](https://fluenthaze.github.io/codex-pulse/#download)获取对应系统和架构的安装包。

## 连接与数据问题

| 问题 | 建议操作 |
| --- | --- |
| 无法连接或找不到 Codex | 确认 Codex 已安装并登录；在偏好设置中选择正确的可执行文件，再刷新 |
| 额度与 Codex 中看到的不同 | 核对是否为同一账号；自定义 Codex 配置目录可能使用另一套账号环境 |
| 找不到聊天或今日没有统计 | 检查所选 sessions 目录，确认记录在这台电脑上且包含有效用量事件；内部审核与子会话不计入 |
| 初次读取较慢 | 等待后台读取完成；较大的近期会话文件仍需要解析，先保留已有数据显示；切到日视图会额外读取最近 15 天 |
| 统计不完整或与账单不同 | Token 来自本机记录，不覆盖其他设备或尚未同步的历史，也不按当前登录账号隔离；以软件中的缺失提示为准 |
| Mac 提示无法打开或已损坏 | 按 [Mac 首次打开](../README.md#mac-首次打开)操作；仍失败时下载最新版并反馈问题 |
| 提醒没有出现 | 检查软件内开关和系统通知权限，并保持软件在后台运行 |

Pulse 不复制或保存登录 Token，不上传聊天正文。额度来自本机 Codex，聊天和 Token 来自所选本地记录；重置公告来自公开第三方服务。日志和截图请先脱敏，不要提交登录凭据或私人聊天内容。

仍有问题时，请在 [Issues](https://github.com/FluentHaze/codex-pulse/issues) 提供系统与架构、Pulse 版本、复现步骤、错误提示及脱敏截图。
