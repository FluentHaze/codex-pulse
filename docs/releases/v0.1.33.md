# v0.1.33 · 全新界面风格与 Token 明细升级

这次更新重点打磨每天都会看到、用到的界面：统一 macOS、Windows 与官网的视觉风格，重新整理 Token 明细的浏览方式，并让今日用量、重置日历和实时会话跟踪更清楚、更顺手。

## 界面风格更新

- **统一新版品牌图标**：应用内标识、macOS Dock／菜单栏、Windows 图标，以及官网导航、产品演示、下载入口和分享图片统一使用新版脉冲 Logo；Windows 图标补齐多种显示缩放尺寸。
- **更清晰的视觉层次**：调整主要数字的字重、说明文字与输出 Token 的颜色，提高深浅主题下的可读性；“剩余／已用”切换改用清晰的选中底色，刷新按钮增加完整的悬停、按下和加载反馈。
- **更协调的布局细节**：修正主题图标居中、表头吸顶、圆角背景溢出及“全部”选中项贴边等问题；弹出菜单取消深色主题下的白色光晕，改为轻阴影和明确边框。
- **滚动时不再挤压内容**：取消占位滚动条，新增跟随滚动位置的细指示条，滚动时出现、停止后淡出，保留滚轮和触控板操作。
- **界面动起来**：加入页面、下拉菜单和消息抽屉的过渡，以及额度环呼吸、预测进度条流光、当前小时柱形扫光和在线状态动效；页面隐藏时暂停持续动画，并尊重系统“减少动态效果”设置。

## Token 明细：从大表格到更易阅读的聊天浏览器

- **紧凑的双栏工作区**：左侧选择聊天，右侧将聊天标题、总用量、轮次数和固定跟踪入口合并为紧凑标题栏；减少留白，一屏能查看更多轮次。
- **重点数据优先**：轮次列表默认展示消息摘要、输入、输出和合计，缓存与推理等详细统计移入轮次抽屉；单页记录隐藏无用的分页控制。
- **点击轮次查看完整消息**：右侧抽屉集中展示该轮完整统计和消息，避免展开正文撑高列表。大数字自动使用 K／M 缩写，小数值保持原样，悬停可查看完整计数。
- **更自然的聊天样式**：用户消息靠右、助手回复靠左，头像放在气泡外侧；用户头像与应用侧栏一致，助手使用清晰的 GPT 矢量图标，连续同角色消息减少重复头像。
- **支持本地图片查看**：聊天记录中仍可访问的本地图片显示为附件卡片，点击即可预览；原文件被移动、删除或无法读取时明确提示，不会把图片或消息上传到远端。
- **正文更干净**：识别附件包装文字，优先展示实际请求；项目筛选中，有名称的项目优先、仅路径的项目随后、“未分类”最后。
- **滚动更统一**：右侧整体滚动，去掉表格内部的小滚动区；修正表头吸顶遮挡消息及边框圆角衔接问题。

## 今日用量：今日柱形与昨日虚线

- 每小时图表升级为**今日蓝色柱形 + 昨日虚线参考**，共享刻度，避免两组细柱拥挤。
- 悬浮可同时查看两天同小时的总量、输入和输出，并在可比较时显示增减百分比；今天尚未到来的时段仍可参考昨日数据。
- 昨日按本机时区的自然日归集，跨午夜记录根据事件时间分别计入对应日期，继续保留跨文件去重与不完整记录提示。
- 汇总、坐标和提示统一标注 Token，较大数字使用 K／M 单位，输出用量采用更清晰的文字颜色。

## 实时会话跟踪更稳定

- 自动模式优先持续读取当前运行中的会话，只在确认其他会话出现进行中的新轮次后接续，不再仅因文件修改时间或列表排序变化跳到别的聊天。
- 各会话分别保留增量读取进度，减少切换造成的重复解析；完成写入、索引更新或旧轮次被重新触碰时，不再轻易抢走当前跟踪对象。
- 固定跟踪仍可随时使用，并可恢复自动跟随。

## 重置日历与官网同步

- 日历日期区增加轻边框和圆角，与右侧当日记录分区更明确。
- 重置预测的百分比与进度条统一为蓝色，概率高低通过填充长度表达，避免高概率被误读为红色警告。
- 官网同步新版 Logo、配色、今日／昨日图表和消息布局；产品演示可切换四个界面，体验额度切换、日历选日、聊天选择及消息抽屉。
- 保留五种语言、深浅主题和移动布局，官网演示使用固定示例数据，不接触本机账号或聊天。
