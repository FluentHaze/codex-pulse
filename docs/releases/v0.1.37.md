# v0.1.37 · 更明显的新版本提示

- 在账号区上方新增常驻更新提示卡，明确显示新版本号、下载进度和更新就绪状态。
- 下载完成后，可直接点击「重启并安装」；只有用户点击才会安装，不弹窗打断使用。
- 窄窗口将提示放在内容区顶部并保持可见，避免侧栏收起或页面滚动时错过更新。
- 保留底部当前运行版本号，提供「查看更新」入口；安装中禁用重复操作，更新失败时提供提示与设置入口。
- 同步简体中文、繁体中文、英语、日语、韩语文案，以及 README 和使用指南；修正过时的版本链接与 Mac 更新说明。

提供 Windows x64 安装版、便携版，以及 macOS Apple Silicon / Intel 的 DMG 和 ZIP，包含应用内更新清单。Mac 使用本地签名，尚未经过 Apple 公证。

v0.1.34 及更早 Mac 版本仍需先手动退出、替换并打开新版一次，之后即可使用自动安装。
