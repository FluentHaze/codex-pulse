# v0.1.36

- 优化额度概览和今日用量图表：支持分钟、小时视图，额度概览另提供最近 15 天的日视图。
- 分钟视图通过并列柱形对比今日与昨日，支持当天内拖动和缩放；底部选区可拖动并调整两端，柱形保持最小宽度。
- 小时视图固定展示当天，完善图表交互、多语言提示与用量统计边界处理。
- 更新官网演示、多语言介绍和安装说明，补充完整使用指南及连接排查文档。

包含 v0.1.35 的 Mac 自动替换与重启更新功能。v0.1.34 及更早版本需手动退出、替换并打开一次，之后即可使用自动安装。

提供 Windows x64 安装版、便携版，以及 macOS Apple Silicon / Intel 的 DMG 和 ZIP；包含应用内更新清单。Mac 使用本地签名，尚未经过 Apple 公证。
