# v0.1.38 · 布局细化与完整动效

- 重组首页图表、最近聊天、重置入口及更新时间，改善卡片内外留白；今日用量采用紧凑工具栏与响应式左右布局。
- 聊天列表在页面可见时自动请求更新，恢复显示时立即刷新；新增聊天进入列表和匹配汇总，保留当前选择与已有内容。
- 今日用量支持精确数值切换和完整数字复制；消息抽屉支持上一轮、下一轮、切轮回顶及复制单轮用量。
- 新增主题圆形扩散、导航和周期滑块、方向切轮、刷新完成反馈与数字更新动效。本轮 Token 按原始数值触发，K/M 缩写未变化时仍可感知更新。
- 增加 Logo、额度环、当前时间标记和预测条的轻量持续动效；后台隐藏时暂停，并遵循系统减少动态效果设置。
- 历史重置节奏图改用细柱、共享刻度、柱顶数字与日期标签，窄窗口支持图表内横向滚动。
- 同步五种语言简介、交互文案、使用指南和技术说明，细化深浅主题与窄窗口排版。

提供 Windows x64 安装版、便携版，以及 macOS Apple Silicon / Intel 的 DMG 和 ZIP，包含应用内更新清单和 SHA-256 校验文件。

Mac 使用本地签名，尚未经过 Apple 公证。v0.1.34 及更早 Mac 版本仍需先手动退出、替换并打开新版一次，之后即可使用自动安装。

验证：单元测试、生产构建及隔离 Electron 界面/交互检查；未进行 Windows 实机安装或真实跨版本自动升级端到端验收。
