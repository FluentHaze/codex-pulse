# 发布检查

- 错误模式：只验证构建、安装包和附件，漏查主 README 与文档目录中的旧版入口，也未核对多语言使用说明是否符合当前行为。
- 原因：将发布说明准备视为文档检查完成，没有对照上一正式版至当前版本的行为变化逐项检查用户入口。
- 预防规则：每次发布前搜索 README、文档目录、使用指南和多语言简介中的版本号及变更功能关键词；逐项对照代码与发布说明。常驻入口优先链接 Releases 或 latest；历史版本说明保留历史内容。报告文档检查结果后才能宣布发布完成。

# 并排卡片的内容高度

- 错误模式：将内容量不同的图表与聊天列表强制等高，并让列表底部操作使用 auto 外边距，产生大块无意义留白。
- 原因：只检查横向对齐，未在完整页面核对内容高度与底部入口距离。
- 预防规则：并排卡片默认按内容决定是否等高；信息列表优先顶部对齐，短列表与空状态不得被相邻图表撑高。截图验收须包含完整卡片及底部操作。

- 补充：仅取消等高会把卡片内的空白转移为卡片外的缺口。需要同时验收整行轮廓；优先重新组合相关入口、让图表适应右栏内容高度，短列表则切换为完整行布局。动效优化应保留适量可感知的状态反馈，不能将“克制”理解为全部去除。
